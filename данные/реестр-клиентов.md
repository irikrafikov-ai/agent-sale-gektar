# Реестр клиентов

Рабочая память агента. Обновляется после каждого прогона — это единственное место, где видно всю базу одним взглядом.

Битрикс остаётся источником истины по стадиям и суммам. Реестр — про то, чего в Битриксе нет: чем клиент дышит, на чём затормозил, каким поводом его брать следующим.

---

## Как заполнять

| Колонка | Что пишу |
|---|---|
| **Клиент** | Имя как в Авито. Если имя в профиле не настоящее — пишу «без имени» и в переписке не обращаюсь по нему |
| **Avito id** | Ключ дедупликации. Именно по нему, не по имени |
| **Чат** | Рабочий чат. Если чатов несколько — здесь тот, в котором ведём диалог |
| **Сделка** | ID в Битриксе |
| **Объявление** | Площадь и цена — от них считается всё остальное |
| **Что известно** | Цель, срок, бюджет, интересующие участки |
| **Возражение** | Дословно словами клиента. Пересказ теряет суть |
| **Касание** | Номер из пяти. `—` если идёт живой диалог |
| **Последний контакт** | Дата и от кого было последнее слово |
| **Следующий шаг** | Конкретный повод, а не «написать» |

Строку не удаляю никогда. Забракованные уходят вниз, в отдельную таблицу.
