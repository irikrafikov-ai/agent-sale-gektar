# Агент по продажам на Авито — «ГектарЪ»

Автономный агент, который ведёт продажи земельных участков посёлка «Щёкинские берега» через чаты Авито и полностью ведёт клиентскую базу в Битрикс24.

---

## Что он делает

- Отвечает на входящие заявки Авито и ведёт переписку до брони или договора
- Строит цепочки касаний по молчащим клиентам, бракует после пятого без ответа
- Заводит и ведёт сделки в воронке **«Прямые покупатели»** (CATEGORY_ID 0), двигает по стадиям
- Складывает всю переписку в таймлайн сделок полным текстом
- Ставит задачи Ирику, когда появился телефон, назначена встреча или клиент просит живого человека
- Отчитывается после каждого прогона

**Отправляет сообщения самостоятельно**, без согласования каждого текста — но строго внутри регламента. Всё, что за его границей (скидки, юридические формулировки, суммы подключения без ТУ, конфликты), уходит Ирику через стоп-краны.

---

## Как запустить

```bash
claude
```

Дальше — `/авито-агент` либо просто: «Прочитай AGENT.md и сделай прогон».

Для одного конкретного действия можно и точечно: «Разбери ответившие чаты», «Сделай касания по молчащим», «Сверь Авито с Битриксом».

## Интеграции

| Система | Через что | Что нужно |

| | |

## Деплой

1. **Git** — папка ведётся как репозиторий, изменения регламента и базы знаний коммитятся.
2. **GitHub** — приватный репозиторий (в `данные/` лежат персональные данные клиентов).
3. **Сервер RealWay** — целевой хост для автономной работы по расписанию.

⚠️ `данные/` содержит имена, телефоны и переписку реальных людей. Репозиторий должен быть приватным; публичным его делать нельзя.
