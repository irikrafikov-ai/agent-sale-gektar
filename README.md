# Агент по продажам на Авито — «ГектарЪ»

Автономный агент, который ведёт продажи земельных участков посёлка «Щёкинские берега» через чаты Авито и полностью ведёт клиентскую базу в Битрикс24.

---

## Что он делает

- Отвечает на входящие заявки Авито и ведёт переписку до брони или договора
- Строит цепочки касаний по молчащим клиентам, бракует после пятого без ответа
- Заводит и ведёт сделки в воронке **«Прямые покупатели»** (CATEGORY_ID 0), двигает по стадиям
- Складывает всю переписку в таймлайн сделок полным текстом
- Ставит задачи Ирику, когда появился телефон, назначена встреча или клиент просит живого человека
- Отчитывается после каждого прогона

**Отправляет сообщения самостоятельно**, без согласования каждого текста — но строго внутри регламента. Всё, что за его границей (скидки, юридические формулировки, суммы подключения без ТУ, конфликты), уходит Ирику через стоп-краны.

## Как запустить

```bash
claude
```

Дальше — `/авито-агент` либо просто: «Прочитай AGENT.md и сделай прогон».

Для одного конкретного действия можно и точечно: «Разбери ответившие чаты», «Сделай касания по молчащим», «Сверь Авито с Битриксом».

## База знаний — отдельный репозиторий

Продуктовые знания (скрипты, цены, возражения, поводы, участки, кадастр, локация, коммуникации) в этот репозиторий **не копируются**. Копия молча разошлась бы с оригиналом — и агент начал бы называть клиентам устаревшие цены, не зная об этом.

| Где | Что |
|---|---|
| Локально | `ГектарЪ/avito-скрипты/` — Ирик правит файлы здесь |
| На сервере | `irikrafikov-ai/gektar-avito-kb` — сервис тянет свежую копию перед каждым прогоном |

Правки нужно пушить в репозиторий базы знаний, иначе сервер их не увидит.

Если база не подтянулась, прогон не падает — но в отчёт уходит предупреждение, и агент работает без цен и фактов. Это состояние надо чинить сразу.

## Сервис

Автономный прогон по расписанию: контейнер поднимается, отрабатывает цикл, шлёт отчёт в Телеграм, выключается.

```
Dockerfile                      сборка образа (Railway)
сервис/
  прогон.py                     точка входа: база знаний → агент → отчёт
  инструменты.py                инструменты агента поверх интеграций
  интеграции/avito.py           Avito API: OAuth, чаты, отправка
  интеграции/bitrix.py          Битрикс через входящий вебхук
  интеграции/telegram.py        отчёты и алерты
  .env.example                  шаблон переменных
деплой/RAILWAY.md               переменные, расписание, первый запуск, диагностика
```

Инструменты названы так же, как MCP-инструменты, на которые ссылается регламент (`avito_send_message`, `b24_crm_update`) — регламент работает на сервере дословно.

**Почему не MCP-коннекторы.** Коннекторы Авито и Битрикса привязаны к аккаунту Claude: URL и токена, которые можно отдать контейнеру, не существует. Сервис ходит в API напрямую и потому не зависит от того, запущен ли Claude.

Внешняя методика продаж в переписке — скилл `chat-sales`. Он про универсальные принципы, `avito-скрипты/` — про этот конкретный проект.

## Деплой

1. **Git** — папка ведётся как репозиторий, изменения регламента и базы знаний коммитятся.
2. **GitHub** — приватный репозиторий (в `данные/` лежат персональные данные клиентов).
3. **Сервер RealWay** — целевой хост для автономной работы по расписанию.

⚠️ `данные/` содержит имена, телефоны и переписку реальных людей. Репозиторий должен быть приватным; публичным его делать нельзя.
