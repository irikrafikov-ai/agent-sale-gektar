# workbench — Claude Code на Railway

Отдельный сервис в проекте Sale-agent. Не трогает агентов: свой Dockerfile,
свой постоянный диск `/data`, без публичного домена.

Зайти с Мака:

    railway ssh -s workbench --session
    claude

Первый раз `claude` попросит войти: откройте ссылку на Маке, вставьте код.
Логин лежит в `/data/claude` и переживает пересборки.

Репозитории для работы клонируйте в `/data/work` — он тоже на диске.
