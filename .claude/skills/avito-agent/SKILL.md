## Порядок запуска

1. **Прочитай `AGENT.md`** — это конституция. Роль, полномочия, стоп-краны, правило цены, главный закон переписки. При конфликте с любым другим файлом прав `AGENT.md`.
2. **Прочитай `регламент/01-рабочий-цикл.md`** — по нему идёт прогон.
3. Дальше подгружай по ситуации, не всё сразу:
   - `регламент/02-битрикс.md` — перед любым касанием CRM
   - `регламент/03-передача-и-стоп-краны.md` — телефон, встреча, просьба живого человека, конфликт
   - `регламент/04-отчёт.md` — в конце прогона
   - `avito-скрипты/АУДИТ-И-СКРИПТЫ-АВИТО.md` — скрипты, возражения, библиотека поводов
   - `avito-скрипты/ЦЕПОЧКА-КАСАНИЙ.md` — касания по молчащим
   - `avito-скрипты/ЛОКАЦИЯ-И-КОММУНИКАЦИИ.md` — место, инфраструктура, коммуникации
   - `avito-скрипты/СХЕМА-УЧАСТКОВ.md`, `КАДАСТР-И-ПЛОЩАДИ.md` — подбор участка
4. **Прочитай `данные/реестр-клиентов.md`** — рабочая память по каждому клиенту.

## Что помнить всегда

- Отправка сообщений — самостоятельно, внутри регламента. Стоп-краны в `AGENT.md` §2 — жёсткие.
- Цена в чате = цена объявления, из которого пришёл клиент. Скидка 10% за 100% оплату.
- Никогда «передам менеджеру».
- Один человек — один чат. Дедупликация по Avito `user_id`, не по имени.
- Каждое отправленное сообщение — комментарием в сделку сразу, а не батчем в конце.
- Не больше 30 сообщений в час.
- **Прогон начинается с шага 0** — забрать задачи и находки от агента по контролю качества (`Агент по контролю качества/`). Он читает мой регламент как эталон и проверяет в том числе мой отчёт. Спорить с находкой можно, игнорировать — нет.
- Журнал прогона — строго `данные/журнал/ГГГГ-ММ-ДД-{утро|вечер}.md`: по имени файла контроль определяет, состоялся ли прогон.

## Если запрос точечный

Не обязательно гнать полный цикл. «Разбери ответившие чаты» — только шаг 2 рабочего цикла. «Сверь Авито с Битриксом» — только шаг 6. Но `AGENT.md` читается в любом случае.
